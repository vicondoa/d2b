# Prototype font

`font.ttf` is DejaVu Sans Bold, used only for prototype rendering so labels are
real horizontal text instead of the shipping 5x7 rotated bitmap.

DejaVu is distributed under the DejaVu Fonts License (a permissive Bitstream
Vera derivative). Font selection is NOT a design conclusion: the ADR should
specify a system UI face resolved through fontconfig rather than bundling one.
