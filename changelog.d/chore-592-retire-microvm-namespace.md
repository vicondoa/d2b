### Changed

- Retired the `microvm.*` compatibility option namespace (ADR 0018 follow-up, #592). `options.microvm` is deleted with no deprecation shim; the VM runner API now lives under the d2b-owned `d2b.vms.<vm>.runner.*` namespace inside the per-VM evaluation. `microvm.hypervisor` is gone (cloud-hypervisor is the only hypervisor d2b ships); `microvm.mem` -> `d2b.vms.<vm>.runner.memory.sizeMiB`, `microvm.vcpu` -> `d2b.vms.<vm>.runner.cpu.count`, `microvm.shares` -> `d2b.vms.<vm>.runner.shares`, `microvm.storeOnDisk`/`storeDisk`/`writableStoreOverlay` -> `d2b.vms.<vm>.runner.store.{onDisk,disk,writableOverlay}`, `microvm.cloud-hypervisor.*` -> `d2b.vms.<vm>.runner.hypervisor.*` (full table in ADR 0018's follow-up note). Every in-tree writer, reader, and the guest-config containment lint migrated in the same change; a config that still sets any `microvm.*` option now fails evaluation with an unknown-option error. Comments that framed the runner as "microvm.nix's cloud-hypervisor runner" now name the broker `SpawnRunner` path.
