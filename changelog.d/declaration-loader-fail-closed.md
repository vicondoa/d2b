### Fixed

- A provider crate missing one of its four per-crate declarations
  (`resource-types.json`, `operations.json`, `registrations.json`,
  `service-catalog.json`) now fails the generators that read them, naming the
  crate and the file, instead of being silently skipped. Renaming a crate's
  declaration file, or adding a provider crate and forgetting its declaration,
  used to shrink the generated type authority, the committed Nix resource
  registry, the broker operation catalog, the provider registration table, the
  service catalog, and the new-graph projection together, with every drift gate
  still green because each one compared the generated bytes against the same
  incomplete input. A crate that deliberately owns no surface of a kind is
  recorded in the shared absence table beside the loaders, with the reason it
  owns none, so a deliberate absence is a reviewable line instead of a branch
  in a loader.
