## Findings (biggest net first)
- duplicate: `relay_grant_and_forwarded_target_grant_fail_independently` (src/authorization.rs:1521) - covered by `relay_and_target_verb_are_independently_required` (src/router.rs:5726). Both pin the same two failures for an adjacent-zone relay caller: no Relay session verb -> `RelayGrantMissing`; Relay verb but no resource grant -> `RelayTargetGrantMissing`. The router test drives the full dispatch path andsurfaces the same two errors end-to-end, so the authorizer-level copy adds nothing.
- trivial: `the_session_reports_its_link_epoch_and_generation` (src/session/zone_link.rs:1120) - asserts two accessors echo constructor wiring (session.epoch()==LinkEpoch::FIRST from ready_link; session.generation()==42 from FakeDriver prevailed). Generation passthrough is already pinned behaviorally by `a_cancel_is_delivered_under_the_sessions_own_generation` (Call::Cancel(11) proves the session's generation is the driver's). Nothing lost.
- gap: `RegistryError::RouteCapacity` (src/registry.rs:689) - no test anywhere in the crate ever hits route-registration capacity exhaustion;(session_seam tests set max_routes_per_session: 1 but only exercise the replace-before-capacity path). A misconfigured cap would ship silently.

- gap: `RegistryError::UnauthenticatedTransport` (src/registry.rs:711-737) - registration rejection for AdjacentZone/Remote evidence without an EnrolledKk Zone(p/ZoneLink subject is never asserted;(relay tests all use the passing EnrolledKk case). Security boundary untested. 
- gap: `route_outcome` classification mapping (src/metrics.rs:578) - BusError -> Ok/Denied/NotFound/Error feeds route metrics, but no test asserts the mapping;(metric tests call `metrics.route` with explicit outcomes instead.). A misclassification would silently skew route-metric labels.
