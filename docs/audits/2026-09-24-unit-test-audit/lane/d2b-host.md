## Findings (biggest net first)
- duplicate: `modules_disabled_locks_required_absent_module` (src/modules.rs:566) - covered by `required_module_locks_even_when_fail_flag_is_false` (src/modules.rs:585). Both pin: required module absent + `modules_disabled` → `HostModulesLocked`, fail-closed, locked list `["kvm"]`. `probe_with` hardcodes `Required => true` for `fail_when_locked` (src/modules.rs:461-465), so the flag=true variant exercises the identical branch with identical assertions; the keeper additionally pins that the flag is ignored for Required.
- duplicate: `stat_failed_for_missing_path` (src/ownership_matrix.rs:512) - covered by `required_missing_entry_reports_not_found_stat_failed` (src/ownership_matrix.rs:764). Both pin: required entry whose path is absent → `OwnershipMismatch::StatFailed`. The keeper asserts strictly more (`not_found: true`); entry kind (Dir vs File) is irrelevant because stat fails before any kind check.
- duplicate: `marker_round_trip_serializable` (src/hardlink_farm.rs:2288) - covered by `marker_round_trip` (src/hardlink_farm.rs:2223). Both pin `GenerationMarker` serde round-trip to an equal value; the keeper does it through `write_generation_marker`/`read_generation_marker`, covering the serde behavior plus file I/O.
- duplicate: `loose_mode_when_group_execute_set` (src/devices.rs:454) - covered by `loose_mode_when_world_bit_set` (src/devices.rs:440). Both pin the same regular-permission-bits branch of `validate_entry` (mode & 0o777 mismatch → `LooseMode`); only the flipped bit differs. The separate special-bits branch is pinned by `loose_mode_when_special_bit_set` (src/devices.rs:447), which stays.
- duplicate: `no_raw_mangle_nat_hooks` (src/nftables.rs:975) - covered by `build_inet_d2b_chains_layout_matches_plan` (src/nftables.rs:946). Both pin the built batch contains only the 4 allowed hooks (the layout test asserts exactly 4 chains with Prerouting/Forward/Output/Input); the helper's Ok path is also exercised by `fake_backend_preserves_foreign_rules` (src/nftables.rs:1115) via `FakeNftBackend::apply`.
- gap: `extract_managed_block` absent-marker path (src/routes.rs:60-67) - `find(HOSTS_MANAGED_BEGIN)?` returning `None` for a hosts file without the d2b-managed block is never exercised; only the render→extract round-trip happy path is pinned. The broker's hosts op consumes this `Option`.
- gap: `gunzip_inflate` error paths `TooShort` / `UnsupportedMethod` / `Truncated` / `Inflate` (src/modules.rs:306-347) - only `MissingMagic` is pinned; a corrupt or overshort `config.gz` (the exact fallback scenario `read_kernel_config_with_fallback` must survive) is untested.
- cross-check: `validation_request_is_bounded_and_typed` (src/host_generation.rs:136) overlaps tests/host_generation.rs (`helper_json_is_bounded_and_redacts_store_details`, `helper_json_rejects_paths_unknown_fields_and_oversize`) which pin the same parse function's bounds/typing at the wire level.
- cross-check: hardlink-farm split-path unit tests (`build_store_view_writes_split_tree_with_guest_host_split` src/hardlink_farm.rs:2328, `build_store_view_refuses_generation_id_collision` src/hardlink_farm.rs:2493, `split_publish_swaps_currents_and_plants_marker_last` src/hardlink_farm.rs:2447) overlap tests/activation_helper_build_farm.rs CLI-level coverage of the same pipeline (verb-level, typed error JSON).
